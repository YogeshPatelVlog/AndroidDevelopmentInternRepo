# Android App Development Internship - Final Project

## Project Overview

This project was developed as part of the Android App Development Internship at Apex Planet Software Pvt. Ltd.

The application demonstrates Android development concepts including UI design, backend integration, Firebase authentication, REST API communication, push notifications, testing, and deployment preparation.

---

## Features

- User Authentication using Firebase
- REST API Integration
- Responsive UI Design
- Push Notifications
- Error Handling
- Unit Testing
- Performance Optimization
